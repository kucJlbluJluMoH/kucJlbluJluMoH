## What I Work On

**Game development (Unity / C#)**
- **The Dark Lands** at Cybermoon Games: modular runtime spell constructor, unit component system (buffs, elemental effects, damage), Lua scripting via MoonSharp for designers, Save/Load, profiling an FPS drop from 200+ to 10 back to 120+.
- **Parts Under Fire & Queue for Takeoff**: online co-op games on Photon PUN2 with proximity voice chat, FSM + NavMesh NPCs, custom URP shaders.
- **[Tactical Drone Commander](https://github.com/kucJlbluJluMoH/TacticalDroneCommander)**: tower defense / RTS hybrid with a layered architecture on VContainer, EventBus, FSM, pooling, UniTask.

**Python & backend**
- **Barbershop booking website**: FastAPI + React, JWT admin panel, Telegram notifications, nginx. 5,000+ unique visitors per month.
- **Telegram moderation bot** (aiogram) for a 2,000+ member community: rule-based spam scoring plus Gemini API classification, runs 24/7 under systemd.
- **SingiHub**: Flask exam-prep site for Singidunum University students, managed through a Telegram admin bot. Peaks at ~4,000 visitors before exam sessions.
